# Fingerprint Generation Logic

This document explains how fingerprinting works in `src/helpers/fingerprint.ts`.

## High-level flow

The final fingerprint is generated by combining:

1. A hashed **audio fingerprint**
2. A hashed **canvas fingerprint**
3. Browser/device metadata

Then hashing the full payload with **SHA-512**.

---

## `getFingerprint()`

`getFingerprint()` is the main entry point.

### Steps performed

1. Compute raw audio signal fingerprint via `audioFingerprint()`.
2. Hash audio fingerprint string with `hashData(...)`.
3. Compute raw canvas pixel fingerprint via `canvasFingerprint()`.
4. Hash canvas fingerprint string with `hashData(...)`.
5. Build a structured object with browser/system properties.
6. `JSON.stringify(...)` that object.
7. Hash the JSON string with `hashData(...)`.
8. Return the resulting SHA-512 hex string.

### Payload fields included before final hash

- `origin` → `window.location.origin`
- `userAgent` → `navigator.userAgent`
- `language` → `navigator.language`
- `screenResolution` → `${window.screen.width}x${window.screen.height}`
- `colorDepth` → `${window.screen.colorDepth}`
- `pixelRatio` → `window.devicePixelRatio`
- `timeZoneOffset` → `${new Date().getTimezoneOffset()}`
- `canvasFingerprint` → hashed canvas data
- `audioFingerprint` → hashed audio data
- `webdriver` → `navigator.webdriver`

---

## `canvasFingerprint()`

Generates a deterministic 2D canvas render and fingerprints the pixel output.

### Rendering recipe

- Canvas size: `200 x 20`
- Draws:
  - multiple colored rectangles
  - text `"Arquitectura Imed <3"` in layered styles/offsets
  - `window.location.origin` near the bottom

### Output

- Reads full pixel buffer with `getImageData(...)`.
- Returns all pixel channel values as a comma-separated string.

### Fallback

- If 2D context is unavailable, returns `""`.

---

## `audioFingerprint()`

Uses Web Audio API offline rendering to produce a stable signal-dependent output.

### Audio graph

- `OfflineAudioContext(1, 5000, 44100)`
- Oscillator:
  - type: `triangle`
  - frequency: `10000`
- Dynamics compressor:
  - threshold: `-50`
  - knee: `40`
  - ratio: `10`
  - attack: `0.003`
  - release: `0.25`

### Output

- Starts rendering (`startRendering()`).
- Reads channel data slice `4500..5000`.
- Returns comma-separated sample values.

### Fallback/error behavior

- If `OfflineAudioContext` is not supported: logs error and resolves `""`.
- On runtime errors: logs error and resolves `""`.
- Disconnects oscillator/compressor after rendering in `finally`.

---

## `hashData(data: string)`

Hashes any string input.

### Primary path (secure)

- Uses `TextEncoder` + `window.crypto.subtle.digest("SHA-512", ...)`.
- Converts bytes to lowercase hex string.

### Fallback path (non-cryptographic)

If `crypto.subtle` is unavailable:

1. Convert each character code point to hex and concatenate.
2. Normalize length to exactly `128` chars:
   - truncate if longer
   - pad with trailing `0` if shorter

> Note: fallback output is deterministic but not cryptographically equivalent to SHA-512.
